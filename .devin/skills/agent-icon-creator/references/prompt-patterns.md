# Prompt Patterns

## Base template

```
[style keywords], 1:1 aspect ratio square, designed for use as a [icon/avatar/logo].
[symbol description]. [composition]. [color strategy with hex values].
[legibility constraint]. [background]. No text, clean edges.
```

## Style keywords

- flat/minimal: "flat vector style, bold simple geometric shapes, minimal detail"
- gradient/glass: "glassmorphism, soft gradient, subtle depth, modern"
- outlined: "line icon style, consistent stroke weight, rounded caps"
- 3D: "soft 3D render, subtle shadows, premium app icon style"
- pixel: "pixel art, limited palette, crisp pixels"
- abstract geometric: "abstract geometric mark, scalable logo symbol"

## Per asset type

- **Icon**: "simple, bold, minimal detail, reads at small sizes"
- **Avatar**: "character-focused, centered composition, friendly"
- **Logo**: "distinctive mark, scalable, professional"

## Refinement loop

If output misses the mark, adjust ONE variable per iteration:
color shift → simplification → style change → symbol swap.
Always restate "1:1 square" and the size context in every prompt.
